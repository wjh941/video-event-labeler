# 视频标注脚本加固设计

## 目标

在不改变现有 CSV 格式、标注流程和 Python 标准库约束的前提下，降低数据损坏、边界请求和前端状态错乱风险，并减少重复的 CSV 解析和前端重复代码。

## 范围

- 保留 `events` 与 `start_time/end_time` 两种 CSV 模式。
- 保留导入递归扫描、自动预标注、备份和浏览器标注行为。
- 删除 `HTML` 中重复的前端函数定义，以最后一套带完整事件编辑/循环播放能力的实现为准。
- 将 CSV 读取和字段校验集中到 `AppState` 的受保护快照中，写入成功后刷新快照。
- 强化原子写入：临时文件写入后 `flush`、`fsync`，替换后尽力同步父目录；失败时清理临时文件。
- 严格处理 HTTP Range：拒绝负数、反向区间、空文件和超出文件大小的请求，返回 `416` 及 `Content-Range: bytes */size`。
- 导入时检测重复 `sample_id` 和重复规范化视频路径，避免产生无法唯一定位的行。

## 非目标

- 不拆分单文件应用，不引入数据库、第三方缓存或异步框架。
- 不重设计 UI，不改变固定行为标签、CSV 字段名或备份目录结构。
- 不实现文件删除同步、视频内容哈希索引或多用户协作锁。

## 错误处理

- CSV 读取时发现空表头、重复字段、缺少样本身份、无效事件 JSON 或重复视频标识，返回明确的 `ValueError`，HTTP 层转换为 `400`。
- Range 错误不泄露文件内容，只返回 `416`。
- 视频响应按固定块流式发送；写入失败保留原文件，删除临时文件；备份只在实际替换前完成，父目录同步失败不否定已经完成的替换。
